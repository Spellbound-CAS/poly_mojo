# Gröbner bases and ideal membership

For coefficient-array inputs, start with the [array workflow](array-systems.md).

A Gröbner basis makes multivariate reduction systematic. It can also answer
whether a polynomial follows from a set of polynomial equations. For example,
$x-y=0$ and $x^2-1=0$ imply $y^2-1=0$. In algebraic terms, $y^2-1$ belongs
to the ideal generated by $x-y$ and $x^2-1$.

## Compute a basis and check membership

<!-- example: docs/examples/tutorial_groebner.mojo -->

The ring assigns variable IDs in the order `x`, `y` and uses lexicographic
order. `groebner` returns a reduced, monic basis, sorted by decreasing leading
monomial. In this example the basis is $[x-y, y^2-1]$.

`membership` returns an optional certificate. When present, it contains
multipliers for the **original generators**, in their original order:

$$
f = \sum_i h_i g_i.
$$

Here the identity can be written
$y^2-1=-(x+y)(x-y)+(x^2-1)$. The checker verifies this identity by polynomial
arithmetic; it does not repeat the Gröbner computation. If the optional result
is empty, the polynomial is not in the ideal. An exhausted budget raises an
error instead of returning an empty result.

## Choose an order deliberately

`LEX`, `GRLEX`, and `GREVLEX` are admissible orders. The choice affects the
basis and the cost of computing it. Lexicographic order is useful for
elimination; degree-based orders are often useful for general reduction.
`KERNEL` is a storage order and is rejected by these algorithms.

Use `reduce` when you already have a basis and want to reduce several
polynomials against it. A nonzero remainder identifies a nonmember when the
basis is a Gröbner basis for the ideal. Dividing by an arbitrary generator
list does not provide the same test.

Cofactor tracking is optional in `groebner` because the witnesses can be
much larger than the basis. `membership` enables it to produce the identity.

## Exact complex coefficients

The same operations accept `QQi`, the Gaussian rational field $\mathbb Q(i)$,
and prime `ModInt`. `QQi` represents rational real and imaginary parts
exactly, without a precision setting. Follow the [complex-coefficient
example](../reference/p4.md#exact-complex-coefficients) for a basis over
$\mathbb Q(i)$.

Rounded complex coefficients use a different domain and cannot enter these
exact algorithms. The [reference](../reference/p4.md) describes the result
and certificate fields; the [theory](../theory/groebner.md) explains reduction,
pair selection, and the membership proof.

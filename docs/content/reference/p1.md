# Representations and arithmetic

All computational methods share an explicit `Budget`; see [budgets and errors](../guides/errors.md).
Fields describe canonical representations; use validated factories when
constructing values and preserve their invariants when inspecting fields.

<!-- api: src/polynomials/packed.mojo PackedPoly -->

`PackedPoly` holds a LEX polynomial over the variables 0..n-1 as one exponent
word per term and a contiguous coefficient list, so large products and powers
build no per-term monomial lists. Its radices are the exact exponent bounds:
leading forms multiply without cancellation over an integral domain, so a
product, power or quotient knows its radix before it is computed.
`packed_mul` and `packed_pow` return no value when the result's key range would
reach 2**62; `packed_divide_exact` returns no value when the divisor does not
divide, as `divide_exact` does.
Convert with `to_sparse` for operations that `PackedPoly` does not provide.

The buffer owns a contiguous list or bounded chunks. Indexing borrows entries;
iteration yields independent coefficient values without flattening the buffer.
`copy()` creates independent storage;
`to_list(budget)` explicitly copies into a contiguous list. See
[dense coefficient storage](contract-p.md#dense-coefficient-storage) for the
buffer's operations.

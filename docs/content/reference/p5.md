# Exact real roots

These operations count and isolate distinct real roots using exact rational arithmetic.
Repeated roots count once. Sturm sequences retain the input and its derivative
without normalization or squarefree preprocessing; every division, including
the terminal zero remainder, has a quotient witness.

The root-count checker verifies polynomial identities and sign variations.
It does not run polynomial division or reconstruct the producer's sequence.
Nonzero constants use a one-element sequence and have no roots. Zero raises
`DOMAIN` for sequence construction, counting, and isolation.

Isolation uses a Cauchy bound rounded up to a power of two and an explicit
bisection worklist. One-sided Taylor signs handle a midpoint that is itself
a repeated root. Output intervals have nonroot dyadic endpoints and width
below `2**-40`; `refine` accepts any positive rational target width.

To recover **all** rational roots, including non-dyadic values such as `1/3`,
isolation also narrows below `1/(2*A*A)`, where `A` is the primitive integer
leading coefficient. The rational-root theorem bounds root denominators by
`A`; Legendre's continued-fraction criterion then finds any such root among
the midpoint's convergents. Each candidate is checked by exact evaluation.
An earlier successful reconstruction avoids unnecessary refinement; an
unsuccessful early attempt never excludes a rational root.
This is rational reconstruction after Sturm bisection, without integer
factorization. Rational midpoint roots remain strictly inside the open
interval returned by `refine`.

`count_roots` requires increasing nonroot endpoints. `sign_on_interval`
accepts singleton intervals and returns no sign if any root lies in the closed
interval. Budget exhaustion raises `LIMIT` and never returns a partial list.
